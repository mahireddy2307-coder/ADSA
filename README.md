# ADSA Interactive Algorithm Visualizer Website

## 📌 Project Overview

The **ADSA Interactive Algorithm Visualizer Website** is a web-based educational project developed to demonstrate and visualize fundamental algorithms in Advanced Data Structures and Algorithms (ADSA).

This website helps students understand how different algorithms work through interactive animations and visual representations.

## 🎯 Objectives

- To understand the working of sorting algorithms.
- To visualize searching algorithms step by step.
- To demonstrate graph traversal algorithms.
- To make learning data structures and algorithms easier and more interactive.

## ✨ Features

- **Sorting Algorithms:** Bubble Sort and Selection Sort.
- **Searching Algorithms:** Linear Search and Binary Search.
- **Graph Traversal:** Breadth-First Search (BFS) and Depth-First Search (DFS).
- Interactive controls and algorithm animations.
- Simple and user-friendly interface.
- Responsive web design.

## 🛠️ Technologies Used

- **HTML5** – Website structure.
- **CSS3** – Styling and layout.
- **JavaScript** – Algorithm logic and interactive visualizations.

## 🚀 How to Run the Project

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in a web browser such as Google Chrome.
4. Select an algorithm and interact with the available controls.
5. Observe how the algorithm works through the visualizations.

No special software installation is required to run the basic website.
